# Changelog

All notable changes to Supernote Cloud Sync are documented here.

The project uses Semantic Versioning.

## 1.0.4 - 2026-07-28

- Let large notebooks open beyond benchmark targets and add privacy-safe
  performance diagnostics and retry guidance.
- Improve mobile and desktop Cloud browsing with safe-area-aware layouts,
  animated transitions, and loading feedback.
- Suspend inactive readers, refine notebook controls, and add desktop toolbar
  zoom actions while preserving mobile gestures.
- Restore complete embedded fonts so Markdown PDFs render correctly in Supernote
  Partner and other PDF viewers.

## 1.0.3 - 2026-07-28

- Add Ko-fi support links to the README and Obsidian plugin metadata.

## 1.0.2 - 2026-07-28

- Expand the README and plugin description to cover the complete feature set.

## 1.0.1 - 2026-07-28

- Clear notebook swipe transforms without static inline style assignment.

## 1.0.0 - 2026-07-28

- Publish the first stable release for the Obsidian community directory.

## 1.0.0-beta.1 - 2026-07-28

- Add Supernote Cloud mirroring, a local notebook reader, embeds, Export, Send
  to Supernote, a Paired folder, transcription, and Automations.
